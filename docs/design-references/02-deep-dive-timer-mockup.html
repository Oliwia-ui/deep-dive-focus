Design decisions

The metaphor supports the clock; it does not replace session truth.

01

One dominant reading

Remaining time owns the center. Activity, task reference, and session state are close enough to scan without competing.

02

Progress becomes ascent

The left rail maps elapsed focus to fictional depth. Zone labels add atmosphere while the numeric timer remains authoritative.

03

Honest parallel metrics

Planned, focused, and paused durations stay separate. The interface never implies that a target equals work completed.

04

Surface is a decision

At zero, the timer pauses and asks for intent. Completion is prominent, but overtime, break, and cancellation remain explicit.

05

Calm, not gamified

Muted teal, sparse sonar marks, and low-frequency bubbles create presence without rewards, streak pressure, or visual noise.

Aqua = live focus / safe primary action
